# De la costa a la ciudad

Práctica de panorámicas 360º realizada con A-Frame.

El proyecto contiene dos escenas:

- `recursos/costa.html`: panorámica de imagen mediante `a-sky`.
- `recursos/ciudad.html`: panorámica de vídeo mediante `a-videosphere`.

Las dos escenas aparecen dentro de `index.html` mediante `iframe`.

## Controles

Se puede arrastrar el ratón para mirar alrededor. En la escena de vídeo, el círculo amarillo permite pausar y reanudar la reproducción.
